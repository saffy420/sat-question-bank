Question info

Choice B is correct. Set the two equations equal to each other: x² − 6x + 5 = 2x − 11.

Subtracting 2x − 11 from both sides gives x² − 8x + 16 = 0, which factors as (x − 4)² = 0.

This has exactly one solution, x = 4, so the line touches the parabola at exactly one point, (4, −3).
